SportsWorld API Documentation

BASE URL for the API: http://localhost:5105/

Url for Athlete: http://localhost:5105/athlete

Table: Athletes

  • GET /Athlete - Returns all athletes

    • Response 200 OK: 

         [
  {
    "id": 1,
    "name": "Cristiano Ronaldo",
    "gender": "Male",
    "price": 100000,
    "image": "Cristiano_Ronaldo.jpg",
    "purchaseStatus": false
  }
  ,...]
  • GET /Athlete/{id} - Returns athletes by ID

    • URL Parameter:

    id(int) Athlete ID

    Response 200 OK:

     {"id": 1,
    "name": "Cristiano Ronaldo",
    "gender": "Male",
    "price": 100000,
    "image": "Cristiano_Ronaldo.jpg",
    "purchaseStatus": false
  }

    Response 404 NOT FOUND: If athlete does not exist

  • POST /Athlete - Adds a new athlete

    • Body: 

     {"id": 1,
    "name": "Cristiano Ronaldo",
    "gender": "Male",
    "price": 100000,
    "image": "Cristiano_Ronaldo.jpg",
    "purchaseStatus": false
  }

    Response 201 Created: Returns created athlete object

  • PUT /Athlete - Updates an existing player

    • Body: 

     {"id": 1,
    "name": "Cristiano Ronaldo",
    "gender": "Male",
    "price": 200000,
    "image": "Cristiano_Ronaldo2.jpg",
    "purchaseStatus": false
  }

    Response 204: Update was successful

  • DELETE/Athlete/{id} - Deletes an athlete by ID

    • Reponse 204: Sucessful deletion

    Response 404: Athlete does not exist

Athlete Schema

Key Type Descirption
Id int The id of the athlete
Name string The name of the athlete
Gender string The gender of the athlete
Price Double The Price of the athlete
Image string The Image of the athlete
PurchaseStatus bool The Purchase Status of the athlete

Url for Finance: http://localhost:5105/finance

Table: Finance

  • GET /Finance - Returns all finance record (Only one row in our database )

    • Response 200 OK:

    [
  {
    "id": 1,
    "moneyLeft": 5000000,
    "numberOfPurchases": 3,
    "moneySpent": 300000
  }
]
  • GET /Finance/{id} - Returns athletes by ID

    • ID in URL:

    ID(int)- Finance ID

    Response 200 OK:

    {
    "id": 1,
    "moneyLeft": 5000000,
    "numberOfPurchases": 3,
    "moneySpent": 300000
  }

    Response 404: Finance record does not exist

  • POST /Finance - Creates a new finance record (only for demostration of full CRUD)
  • PUT /Finance - Updates an existing finance record (For example: MoneyLeft, NumberOfPurchases, MoneySpent)

    • Body:

    {
    "id": 1,
    "moneyLeft": 400000,
    "numberOfPurchases": 1,
    "moneySpent": 200000
  }

    Response 200 OK: Returns updates finance object

  • DELETE /Finance/{id} - Deletes a finance record by ID

    Response 204: Successful deletion

    Response 404: Finance record does not exist

Finance Schema

Key Type Descirption
Id int The id of the Finance row
MoneyLeft Decimal Current balance available for spending
NumberOfPurchases int How many athletes that has been purchased
MoneySpent decimal How much money have been spent
